# Changelog

## v0.9.7 (2026-10-21)

**资料库维护（设置 → 工具）**
- 新增「收进存储」：只把「在游戏目录里、但存储里没有」的组件复制进存储，先告知模组数 / 文件夹数 / 预计体积；游戏目录只读不动，已有副本不覆盖。
- 新增「清空记录」：只清记录、所有权索引与 bin 账本；游戏目录、存储副本、备份都不动；清空前把三个文件另存为 `.cleared-时间戳` 副本。

**结构识别：旧链退役**
- 删除按文件夹名猜结构的整套扫描器（约 210 行），识别只由分析器负责；新结构必须先落 fixture 再改代码。
- 认不出结构时不再自动猜根，改为显式询问「整体安装为 mod 还是 dlc」；取消即什么也不写。
- bin 文件改为按各自 `bin/` 根复制（原来取第一个根，多根时可能复制错源）；包内两个根写同一路径时直接拒绝导入。

**之前的修复一并进入本版**
- 删除 bin-only 记录不再误删整个存储目录；`_w3mm_staging` 空壳会被清理；`mods.settings` 读取失败会留诊断日志。
- 孤儿接管只登记、不复制；只带 bin 负载的模组文件夹也能被发现；预设按记录 ID 保存（旧预设仍可读）；备份目录按记录 ID 存放；预设文件损坏会保留副本并提示。

**工程**
- 新增「手工回归矩阵」（`docs\regression-matrix.md`）与一条命令出包脚本（`tools\release.ps1`：测试 → fixtures → 打包 → 校验产物）。
- 新增设置隔离守卫测试：测试版与正式版的数据目录必须不同。

## v0.9.6 (2026-10-16)

自 v0.9.4 以来的第一批完整记录（v0.9.3–v0.9.5 未单独记载）。

**部署内核（第 16 项，全部由测试驱动）**
- 启用 / 禁用 / 删除三条路径改由同一个「步骤引擎」执行：目标永不直接删除，先移入 `<游戏>\_w3mm_staging`，失败按逆序回滚，无法回滚的步骤单独报告。
- bin 文件可逆：启用前的内容按内容哈希留档，停用/删除时还原（别人在后面写过就还原成别人的那份）；磁盘内容被人改过或没有记录时保持不动并说明原因。
- 删除 bin-only 包不再误删整个存储目录。
- 未完成的操作用日志留痕，启动时提示，并可「我已处理」归档。
- 失败提示精确到「哪个组件 + 什么原因」，不再只说「失败」。
- 临时目录没清理干净会被报告出来，不再静默。

**部署后漂移检测（第 17 项）**
- 「检查资料库」现在会对比索引与实际磁盘：记录为已部署但已消失、或内容被外部改动，都会列出（只读、不自动修复）。

**孤儿接管（第 18 项）**
- 游戏目录里已有的模组可以「接管」进资料库：**只登记，不复制、不移动、不删除任何文件**；被别人占用的路径会拒绝并点名。
- 预设改按记录 ID 记录（旧预设仍可读）；备份目录改按记录 ID 存放；设置里那句与实际不符的备份说明已改正。
- 只带 bin 负载的模组文件夹现在也能被发现。

**其它修复**
- 语言切换的 handler 不再累积；测试版不再读到正式版的设置；诊断日志不再写死 `Z:\griffin_import.log`。
- 版本号收敛为单一来源（`Core\AppInfo`），并有守卫测试防止再散落。
- 若干「静默吞掉」的地方改为明确报告（存储写入、日志读取、预设文件损坏）。
